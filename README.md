# Demo Closer AI

Bonjour. Construction d'un Outils Ultra Smart qui discute avec les prospects avec pour mission d'obtenir un rendez-vous pour une démo. L'utilisateur connecte sa base de donnée Odoo, pour que l'outils accède au module CRM pour détecté les prospects. L'utilisateur crée un compte pour accéder à l'outils (uniquement via mail/mot de passe, sans confirmation par mail, pas besoin de connexion avec Google). L'outils est propulsé par GPT 5.6 Sol qui est configuré avec toutes les configuration natifs pour une meilleure performance. Ajoute tout les scopes natifs de Odoo qui permet de gérer les modules de CRM, de Contact (ajout des scopes natifs complet de chaque modules qui permet à l'outils de fonctionné correctement et accomplir ses objectifs réellement dans Odoo). Lovable Cloud est connecté, avec la persistance des données de l'utilisateur en temps réel. Lovable AI est connecté, avec les Edge Function qui sont nécessaires.  Consigne obligatoire à suivre: Reste sur une implémentation simple, sans ajouter de bibliothèques lourdes, pour optimiser les performances et le coût de génération.
